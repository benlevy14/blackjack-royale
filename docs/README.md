# Blackjack Royale

משחק בלאק ג'ק עצמאי לדפדפן. לפתיחה, יש להפעיל את `index.html`.

## מבנה

- `index.html` - מעטפת המשחק והנגישות
- `src/game.js` - מנוע המשחק, חוקי השולחן והשמע
- `src/styles.css` - עיצוב רספונסיבי ואנימציות
- `data/rules.json` - תיעוד הגדרות השולחן
- `assets/` - נכסים חזותיים

## חוקי שולחן

6 חפיסות, חיתוך ב־75%, דילר עומד על 17 רך, Blackjack משלם 3:2, ביטוח 2:1, הכפלה אחרי פיצול מותרת, פיצול יחיד בכל סיבוב.
